## 3. 多Agent启动与管理

### 3.1 创建Agent配置（Profile）

每个Agent需要独立的Hermes profile，含SOUL.md角色定义。

```bash
# 克隆默认配置
for agent in project-manager architect backend-dev frontend-dev devops qa-engineer github-release; do
  hermes profile create "$agent" --clone
done

# 配置模型
for agent in project-manager architect backend-dev frontend-dev devops qa-engineer github-release; do
  hermes config set model.default deepseek-v4-pro --profile "$agent"
  hermes config set model.provider deepseek --profile "$agent"
done

# 复制API密钥
for agent in project-manager architect backend-dev frontend-dev devops qa-engineer github-release; do
  cp ~/.hermes/.env ~/.hermes/profiles/$agent/.env
done
```

### 3.2 tmux舰队启动

```bash
# 创建舰队tmux会话
tmux new-session -d -s agentark-fleet -n pm -x 160 -y 40 \
  "hermes -p project-manager chat"

# 添加Agent窗口（按顺序依次添加）
for agent in architect backend-dev frontend-dev devops qa-engineer github-release; do
  tmux new-window -t agentark-fleet -n "$agent" "hermes -p $agent chat"
done

# 验证：预期7个窗口、7个hermes进程
tmux list-windows -t agentark-fleet
ps aux | grep "hermes -p" | grep -v grep | wc -l
```

### 3.3 tmux舰队操作

| 操作 | 命令 |
|------|------|
| 附加到舰队 | `tmux attach -t agentark-fleet` |
| 切换窗口 | `Ctrl+B` + 数字键（0-6） |
| 分离会话 | `Ctrl+B d` |
| 列出窗口 | `tmux list-windows -t agentark-fleet` |
| 发任务给Agent | `tmux send-keys -t agentark-fleet:pm "你的任务" Enter` |
| 查看Agent输出 | `tmux capture-pane -t agentark-fleet:pm -p -S -30` |
| 杀死单个Agent | `tmux kill-window -t agentark-fleet:pm` |
| 毁灭整个舰队 | `tmux kill-session -t agentark-fleet` |

## 4. 跨机器LAN组网

### 4.1 前置条件

```bash
# 每台Mac安装依赖
pip install zeroconf psutil

# 配置SSH免密（每台机器之间）
ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519_fleet
ssh-copy-id -i ~/.ssh/id_ed25519_fleet mac-b.local
ssh-copy-id -i ~/.ssh/id_ed25519_fleet mac-mini.local
```

### 4.2 LAN发现

```bash
# 快速扫描（4秒）
agentark fleet lan scan

# 持续发现（后台运行）
agentark fleet lan discover
```

**mDNS服务：** 通过Bonjour/Zeroconf协议，服务类型 `_agentark-fleet._tcp.local.`，端口 9922。

TXT记录携带：machine_id、hostname、role、profiles、skills_count、has_gpu、gpu_names。

### 4.3 远程任务调度

```bash
# GPU任务调度到有GPU的节点
agentark fleet dispatch "Train model" --gpu --gpu-memory-mb 16000

# CPU密集型任务
agentark fleet dispatch "Analyze data" --cpu-cores 8 --ram-mb 8192

# 指定目标机器
agentark fleet dispatch "Scrape" --target MacBook-Pro-2.local

# 干跑（看匹配结果不执行）
agentark fleet dispatch "Build UI" --dry-run

# 查看任务队列
agentark fleet queue
```

### 4.4 调度评分算法

任务匹配采用加权评分（0-100分），硬约束（不满足直接0分）：

| 约束条件 | GPU任务权重 | CPU任务权重 |
|----------|-----------|------------|
| GPU匹配 | 40% | 0% |
| CPU空闲 | 25% | 45% |
| RAM空闲 | 15% | 25% |
| 当前负载 | 10% | 15% |
| LAN延迟 | 10% | 15% |

**硬约束（任意不满足→分数归零）：**
- GPU任务且节点无GPU
- GPU显存不足
- CPU核心低于最低要求
- Docker任务且节点无Docker
- OS不匹配

## 5. 节点心跳与健康监控

### 5.1 双通道心跳机制

```
每2分钟（每节点）：
  ├─ mDNS扫描 → 发现LAN邻居
  ├─ SSH测试 → 验证邻居可达性
  ├─ 本地探测 → CPU/GPU/RAM/Disk/Profiles/Skills
  ├─ 写入 → fleet/nodes/<machine_id>.json
  └─ git push → GitHub同步（尽力而为）
```

### 5.2 心跳Cron配置

**在每台舰队机器上设置：**

```bash
# Origin (Mac-A):
cronjob(action='create',
  name='⚓ Fleet 心跳 (LAN+GitHub)',
  schedule='every 2m',
  script='scripts/fleet_heartbeat.py',
  no_agent=True,
  enabled_toolsets=['terminal', 'file'],
  workdir='~/Desktop/2026workspace/agentark')
```

### 5.3 舰队健康看门狗

**每10分钟自动巡检（已部署于 job `5b3c6bb5623f`）：**

```
检查项：
  1. tmux窗口存活 → agentark-fleet 会话是否存在，7个窗口是否完整
  2. Agent进程 → ps aux | grep "hermes -p" 预期7个
  3. Dashboard → curl localhost:8765/ 返回200
  4. 舰队状态 → agentark fleet status（Agent在线数）
```

**手动检查：**
```bash
# 查看tmux健康
tmux list-windows -t agentark-fleet 2>&1

# 检查Dashboard
curl -s -o /dev/null -w "%{http_code}" http://localhost:8765/

# 查看舰队状态
cd ~/Desktop/2026workspace/agentark && agentark fleet status

# 查看所有cron任务
cronjob(action='list')
```

### 5.4 告警升级规则

| 级别 | 条件 | 动作 |
|------|------|------|
| SILENT | 一切正常 | 静默，仅记录心跳 |
| WARN | 1-2个Agent离线 | 自动重启，记录日志 |
| ALERT | 3+ Agent离线或Dashboard宕机 | 发送IM通知老卢 |
| CRITICAL | Origin心跳丢失>5分钟 | Mac-B接管为Origin（Failover） |

## 6. Dashboard监控面板

### 6.1 Dashboard概述

- **服务地址：** `http://localhost:8765`
- **实现：** 单文件Python（stdlib，零依赖）
- **自动刷新：** 30秒
- **主题：** GitHub暗色风格 (`#0d1117`)

### 6.2 面板功能

| 模块 | 数据源 | 说明 |
|------|--------|------|
| 状态徽章 | `pgrep hermes` / `claude auth status` | Hermes ✓/✗、Claude ✓/✗ |
| Token用量 | `~/.hermes/state.db` SQLite | 今日/7天/30天，按模型分 |
| 配额倒计时 | state.db（按模型解析） | 剩余<4小时时脉冲警告 |
| Claude会话 | `~/.claude/sessions/*.json` | 14天活动柱状图 |
| Hermes进程 | `pgrep -fl hermes` | 进程列表 |
| Token趋势 | state.db聚合 | 14天日用量折线图 |

### 6.3 API接口

| 端点 | 方法 | 用途 |
|------|------|------|
| `/` | GET | 完整Dashboard HTML |
| `/api/hermes/usage` | GET | Token用量JSON |
| `/api/hermes/procs` | GET | 运行中的Hermes进程 |
| `/api/claude/auth` | GET | Claude认证状态 |
| `/api/claude/stats` | GET | Claude会话统计 |
| `/api/meetings/logs` | GET | AutoGen会议日志 |
| `/api/health` | GET | 健康检查 |
| `/api/action/claude` | POST | 启动Claude Code |
| `/api/action/hermes` | POST | 启动Hermes CLI |

### 6.4 Dashboard启动

```bash
# 手动启动
cd ~/hermes-dashboard && python3 server.py &

# 检查进程
lsof -i :8765

# 设置开机自启（macOS launchd）
# plist位置：~/Library/LaunchAgents/com.user.hermes-dashboard.plist
```

## 7. 故障排除

### 7.1 tmux会话丢失

**症状：** `tmux list-windows -t agentark-fleet` 返回 "no server running"

**修复：**
```bash
# 重建舰队
tmux new-session -d -s agentark-fleet -n pm -x 160 -y 40 "hermes -p project-manager chat"
for agent in architect backend-dev frontend-dev devops qa-engineer github-release; do
  tmux new-window -t agentark-fleet -n "$agent" "hermes -p $agent chat"
done
```

### 7.2 单个Agent挂掉

**症状：** 某个窗口缺失，hermes进程少一个

**修复：**
```bash
# 重建单个Agent窗口
tmux new-window -t agentark-fleet -n "agent-name" "hermes -p agent-name chat"
```

### 7.3 Dashboard无法访问

**症状：** `curl localhost:8765/` 无响应

**排查步骤：**
```bash
# 1. 检查端口
lsof -i :8765

# 2. 如果没有进程，重启Dashboard
cd ~/hermes-dashboard && python3 server.py &

# 3. 检查日志
cat ~/hermes-dashboard/dashboard.log
```

### 7.4 LAN发现找不到邻居

**排查：**
```bash
# 确认zeroconf已安装
pip list | grep zeroconf

# 确认在同一局域网
ping mac-b.local

# 确认SSH可达
ssh mac-b.local "echo hello"

# 手动探测
agentark fleet probe
```

### 7.5 GitHub同步失败

**症状：** `fleet_heartbeat.py` git push报错

**影响：** LAN通道仍可用，不影响本地舰队运行。GitHub同步是冗余通道。

**修复：**
```bash
cd ~/Desktop/2026workspace/agentark
git remote -v                                # 确认使用HTTPS
git config --global credential.helper osxkeychain  # 使用macOS钥匙串
git pull --rebase origin main                # 拉取最新
git push origin main                         # 重试推送
```

### 7.6 Agent执行卡住不动

**排查：**
```bash
# 查看Agent最后输出
tmux capture-pane -t agentark-fleet:pm -p -S -20

# 发送中断信号
tmux send-keys -t agentark-fleet:pm C-c

# 如果无响应，重启Agent
tmux kill-window -t agentark-fleet:pm
tmux new-window -t agentark-fleet -n pm "hermes -p project-manager chat"
```

## 8. 命令速查表

### 8.1 舰队管理

```bash
agentark fleet status              # 舰队状态总览
agentark fleet nodes               # 节点列表（含角色、心跳、项目）
agentark fleet probe               # 本机资源探测
agentark fleet init-fleet          # 初始化Origin舰队
agentark fleet init                # 初始化tmux多Agent舰队
```

### 8.2 LAN组网

```bash
agentark fleet lan scan            # 快速LAN扫描（4秒）
agentark fleet lan discover        # 持续LAN发现
agentark fleet dispatch <task>     # 跨机器任务调度
  --gpu                            # 需要GPU
  --gpu-memory-mb <MB>            # GPU显存要求
  --cpu-cores <N>                  # CPU核心要求
  --ram-mb <MB>                    # 内存要求
  --target <hostname>              # 指定目标机器
  --dry-run                        # 干跑（只评分不执行）
agentark fleet queue               # 查看任务队列
```

### 8.3 tmux舰队操作

```bash
tmux attach -t agentark-fleet          # 附加到舰队终端
tmux detach                        # 分离（Ctrl+B d）
tmux list-windows -t agentark-fleet    # 列出所有Agent窗口
tmux send-keys -t agentark-fleet:pm "任务" Enter  # 派发任务
tmux capture-pane -t agentark-fleet:pm -p -S -20   # 读取最后20行
tmux kill-window -t agentark-fleet:pm  # 关闭某个Agent
tmux kill-session -t agentark-fleet    # 关闭整个舰队
```

### 8.4 监控与调试

